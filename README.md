# ⚖️ LEET 기출 마스터 (LEET Master)

법학적성시험(LEET) 공식 기출문제 실전 인터랙티브 트레이닝 웹 애플리케이션입니다.

## ✨ 주요 기능
- **📖 언어이해 3-in-1 세트 뷰**: 제시문 고정 및 3개 문항 동시 풀이/채점
- **💡 추리논증 단일 문항 뷰**: 실전 모의 풀이 및 즉시 정답 피드백
- **🔀 안전한 Fisher-Yates 랜덤 셔플**: 세트 내부 무결성을 100% 보존하며 무작위 순서 풀이
- **❌ 오답 노트 및 성적표**: 풀이 기록 및 오답 문항 브라우저 로컬 자동 영구 저장
- **📱 모바일 / 태블릿 완벽 대응 (PWA)**: 지문/문제 탭 전환 UI 및 '홈 화면에 추가' 지원

## 🚀 실행 방법
별도의 서버 설치 없이 브라우저에서 `index.html`을 열어 즉시 사용하실 수 있습니다.
