모바일 / 태블릿 접속 방법

1. 동일 와이파이(Wi-Fi) 접속 (가장 빠름)

스마트폰/아이패드를 Mac과 같은 와이파이에 연결한 뒤 브라우저 주소창에 아래 주소를 입력하세요:

http://localhost:8080

2. 홈 화면에 앱으로 추가 (PWA)

모바일 Safari나 Chrome에서 [공유] ➔ [홈 화면에 추가]를 누르면 일반 앱처럼 전체화면으로 이용 가능합니다.

3. 무료 웹 호스팅 배포 (GitHub Pages 등)

본 정적 웹앱을 GitHub Pages나 Vercel에 업로드하면 언제 어디서든 스마트폰으로 접속할 수 있습니다.
